How do I do this with next.js app router?

Yes. With Next.js App Router, this is actually pretty clean. You don't need to manually create sitemap.xml.

For Instaweb, I'd start with the built-in Next.js Metadata Sitemap API.

1. Create app/sitemap.ts

Your GitHub repo should contain:

instaweb/
├── app/
│   ├── layout.tsx
│   ├── page.tsx
│   ├── robots.ts
│   └── sitemap.ts
├── public/
├── package.json
└── ...

Create:

app/sitemap.ts

with:

import type { MetadataRoute } from "next";


export default function sitemap(): MetadataRoute.Sitemap {
  const baseUrl = "https://instaweb.agency";


  return [
    {
      url: baseUrl,
      lastModified: new Date(),
      changeFrequency: "weekly",
      priority: 1,
    },
    {
      url: `${baseUrl}/pricing`,
      lastModified: new Date(),
      changeFrequency: "monthly",
      priority: 0.8,
    },
    {
      url: `${baseUrl}/about`,
      lastModified: new Date(),
      changeFrequency: "monthly",
      priority: 0.6,
    },
    {
      url: `${baseUrl}/contact`,
      lastModified: new Date(),
      changeFrequency: "monthly",
      priority: 0.6,
    },
  ];
}

That's it.

Next.js will automatically expose it at:

https://instaweb.agency/sitemap.xml

You don't need to create that XML file yourself.

2. Add robots.ts

I'd also create:

app/robots.ts
import type { MetadataRoute } from "next";


export default function robots(): MetadataRoute.Robots {
  const baseUrl = "https://instaweb.agency";


  return {
    rules: {
      userAgent: "*",
      allow: "/",
    },
    sitemap: `${baseUrl}/sitemap.xml`,
  };
}

That gives you:

https://instaweb.agency/robots.txt

with the sitemap automatically referenced.
